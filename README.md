# Dr. M. Mary Anupama - Biochemistry & Biotechnology Hub

A modern, responsive academic repository preserving and showcasing curated lecture notes, digital textbooks, laboratory protocols, and research dissertations in Molecular Life Sciences and Medical Biochemistry by **Dr. M. Mary Anupama, Ph.D.**

---

## 🌟 Features
- **11 Subject Modules**: Clinical Biochemistry, Immunology, Intermediary Metabolism, Enzymology, Cell Biology, Food Safety, Human Physiology, Lab Protocols, and more.
- **Featured Books & Research**: Includes *Fundamentals of Biochemistry by AC Deb*, Dr. Anupama's complete *Ph.D. Thesis on Bioethanol Production*, and *Bioanalytical Techniques*.
- **Real-Time Search & Filtering**: Instant search across all 70 topics and documents.
- **Light & Dark Mode**: Modern design with automatic theme persistence.
- **Zero Build Dependencies**: Pure HTML5, CSS3, and Vanilla JavaScript.

---

## 🚀 How to Deploy to GitHub Pages (1-Minute Guide)

You can copy or initialize this `Website/` folder into a new Git repository and deploy it to GitHub Pages in seconds:

1. **Initialize Git in the `Website/` folder**:
   ```bash
   cd /path/to/Website
   git init
   git add .
   git commit -m "Initial commit: Dr. Anupama Biochemistry Hub"
   ```

2. **Push to your GitHub repository**:
   ```bash
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/biochemistry-hub.git
   git push -u origin main
   ```

3. **Enable GitHub Pages**:
   - Go to your GitHub repository **Settings** → **Pages**.
   - Under **Build and deployment** > **Branch**, select `main` branch and `/ (root)` folder.
   - Click **Save**. Your site will be live at `https://YOUR_USERNAME.github.io/biochemistry-hub/`.
